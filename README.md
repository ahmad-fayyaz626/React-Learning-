# React Learning Repository

## Overview

This repository documents my React learning journey through a series of daily lessons and practical exercises. Each folder represents a day of learning and contains code examples, experiments, notes, and small projects covering the concepts studied during that session.

The purpose of this repository is to maintain a structured record of progress while building a solid understanding of React and modern frontend development practices.

---

## Repository Structure

```text
React-Learning/
│
├── Day1/
├── Day2/
├── Day3/
├── Day4/
├── Day5/
└── ...
```

Each day's folder may contain:

* Concept demonstrations
* Practice exercises
* Mini projects
* Notes and observations
* React experiments

## Running the Project

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd React-Learning
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
